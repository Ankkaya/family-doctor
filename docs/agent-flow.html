部署：真实 Embedding 配置与迁移
  • backend 执行 npx prisma migrate deploy，新增独立 semantic_embedding / model / hash 字段；旧哈希向量不再查询。
  • 后端配置 MEDICINE_EMBEDDING_BASE_URL（兼容 embeddings 接口的服务地址）、MEDICINE_EMBEDDING_API_KEY、MEDICINE_EMBEDDING_MODEL、MEDICINE_EMBEDDING_DIMENSIONS（须等于模型真实输出维度）。
  • MEDICINE_SIMILARITY_THRESHOLD 默认 0.65，仅作初始值，需结合选定模型与测试集校准；不限制药名精确命中。
  • AGENT_INTERNAL_TOKEN 在两端保持一致；BACKEND_BASE_URL 必须指向后端内网地址。默认 Agent 调用超时 120 秒，冷启动批量生成向量可能需要按药箱规模调整 AGENT_TIMEOUT_MS。
  • 精确药名查询无需 Embedding 配置；症状检索未配置模型或模型不可用时显式失败，不能当作“药箱没有匹配药”。
  • 管理端调试需提供目标 userId 与 householdId；工具会校验目标用户的家庭成员关系，不允许随意遍历其他家庭。调试凭证由后端签名，不写入模型消息、运行事件或执行追踪。

已实现 general 一次性回复，以及 medicine 原生药品工具调用、工具内部切题评估、按需重写和主模型两次上限。待优化：回答结束后分类提取健康事实，作为独立候选资料保存。AG-UI 已接通权限、上下文和摘要回写，旧普通与 NDJSON 问诊入口已移除。
